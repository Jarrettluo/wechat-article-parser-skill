# Wechat Article Parser

> 微信公众号文章解析技能，用于抓取和总结微信文章内容。当用户提供微信文章链接（mp.weixin.qq.com）或要求解读微信文章时使用此技能。

## 安装

将本仓库放到 OpenClaw 技能目录即可使用：

```bash
git clone <本仓库地址> ~/.openclaw/workspace/skills/wechat-article-parser-skill
# 或放入 ~/.openclaw/skills/
```

## 配置

如需 API Key、邮箱授权码等配置，请参考 `SKILL.md` 中的说明，通过环境变量或本地 `.env` 文件设置（**不要提交到仓库**）。

详见 [SKILL.md](./SKILL.md)。
